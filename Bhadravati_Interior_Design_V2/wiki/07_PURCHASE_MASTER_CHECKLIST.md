# Purchase master checklist — Bhadravati (print before money leaves)

**Use:** one sheet at the **authorised yard / hardware counter**. Tick **before unload**. Photograph stamps, QR, and unopened boxes.

**Job:** kitchen **shutters only** on existing black granite + **3-door** wardrobe (54 × 90 × 19.20 in).  
**Date:** 2026-08-12. **Not a bid.** Sources: wiki `01`–`06`, `BOARD_DECISION.md`.

---

## A. Global (every visit)

- [ ] GST tax invoice: **brand + series + SKU + thickness + qty + finish**
- [ ] Authorised dealer (not a polybag from a roadside stall)
- [ ] Photograph **ISI + IS number + CML** on **every** board edge
- [ ] Century: **CenturyPromise QR on every sheet before the first cut**; generate e-warranty
- [ ] Greenply: warranty portal registration + ISI/CML photo
- [ ] Mic thickness in **three places**. Doors: **19 mm ply** or **18 mm** only if that mill’s nominal (Boilo/HDHMR). **Reject 16 mm doors**
- [ ] Cut-test one sheet: **no core gaps / pin holes** (0.8 mm laminate will telegraph)
- [ ] Website ?/sqft **ignored** unless the quote is **19 mm landed** (`01`)
- [ ] Keep empty hardware **cartons + holograms** until handover

## F. Hardware (`05`) — named SKU + carton + hologram

### Hinges

- [ ] **Hettich Sensys 8645i** 110° **integrated** Silent System (invoice says **8645i**, not “Hettich 110°”)
- [ ] Overlay / half-overlay / inset **named**; System **8000** plates
- [ ] **Not Onsys**. Not Intermat + clip-on damper. Not “Godrej hinges”
- [ ] Wardrobe: **5 cups per 90 in leaf** × 3 leaves = **15 working** + **2 spare hinges + 2 plates**
- [ ] Logo **moulded/etched on metal**; hologram on box; **no loose polybag**
- [ ] Peer only if named: Häfele Metalla **with soft-close** (not 311.88.xxx) or Blum **71B3550** family

### Channels (if drawers exist — W-01 ~9.5 in band)

- [ ] Heavy: **KA 5632** 45 kg **measured length** (350–400 mm typical; **not** 488 mm)
- [ ] Soft-close light: **KA 4732 Silent System 35 kg**
- [ ] Do not assume 5632 Silent = 45 kg
- [ ] Spare: **1 pair same length**

### Lock (not a hinge)

- [ ] **Godrej Curvo 8010** (25 mm) — **8011** if finished stack >25 mm
- [ ] Invoice says **Curvo 8010**, not “Godrej lock”
- [ ] Spare: 1 complete lock + extra key; photograph key number

### Rail

- [ ] Oval **30 × 15 mm** + **SL 322** (or Ebco WRF) **2 ends + 1 mid-support** on 54 in
- [ ] Reject unsupported span; reject round MS pipe

### Screws / pulls

- [ ] **SS304** kitchen / wet-risk / plinth; **factory screws in the hinge box** for cups
- [ ] Pulls: **recessed brushed stainless** J / finger / J-profile — **no bar / D / knob / gold**
- [ ] Spare: **2 extra recessed pulls**; SS304 **+20%**
