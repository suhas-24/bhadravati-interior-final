## Condensed RACI (studio shorthand)

For Bhadravati’s small-team reality, collapse to six hats:

| Hat | Owns phases | Covers roles |
|---|---|---|
| **Space Planner** | 2–4, co-owns 3/20 | Space Planner + Human Factors |
| **Materials** | 6–8, co-owns 7/14 | Materials + Color + Wellness |
| **Lighting** | 9–11 | Lighting + Acoustics support + Systems questions |
| **Documentation** | 17–18, co-owns 21 | CAD/BIM + CD/specs + Handover Editor |
| **QA** | 20 (gates 15–16) | QA Reviewer; AI hallucination checks |
| **Portfolio** | 22 | Portfolio Curator; case-study export |

**Engagement Lead / Project Manager / Client Strategist** remain cross-cutting (phases 0, 1, 19).  
**FF&E Specifier + Cost Lead** pair on phases 13–14.  
**Visualization + 3D** pair on phases 15–16 under QA gate.

## Handoff checklist between roles

1. **Strategist ? Planner:** locked brief + non-negotiables.  
2. **Planner ? Concept/Materials:** zoning + clearance narrative + register IDs (K-01, W-01).  
3. **Materials ? Lighting/FF&E/Cost:** locked SKUs + sheen + sample plan.  
4. **Viz/3D ? QA:** labeled conceptual renders + camera list.  
5. **QA ? Documentation/PM:** punch-closed assets only.  
6. **Documentation ? Handover Editor:** schedules + assumptions (no silent dim invention).  
7. **Handover Editor ? PDF agent:** structured control docs, not ad-hoc chat.  
8. **All ? Portfolio Curator:** problem ? constraints ? process ? outcome ? learning.
