# Plywood + hardware recommendation — Bhadravati interiors

**Project:** Kitchen shutters-only on existing black granite + 3-door wardrobe niche  
**Site:** Bhadravati, Karnataka — monsoon humidity, laterite dust, termite/borer risk  
**Locked finishes:** Century **S1241 MT Latte** (kitchen, 0.8 mm) · Century **84689 SU Idria Oak** (wardrobe, 0.8 mm) · E3 ABS **2 mm kitchen / 1 mm wardrobe** · brushed stainless **recessed** pulls (not bar pulls) · **3000 K** lighting  
**Date:** 2026-08-12  
**Status:** SUPERSEDED as the client lock by `BOARD_DECISION.md` (2026-08-12). Keep this file as hardware SKU detail + source notes. **Do not** use the Sainik-wardrobe primary in §2/§10 — wardrobe primary is Club Prime / Greenply 710 Marine; Sainik is contingency only.

## 0. How to read this note

- **Manufacturer pages** = claims. Cite them; do not upgrade them.
- **Retailer / modular-kitchen blogs** = marketing mixed with practice. Useful for availability and carpenter habit; not proof of IS grade.
- **Quora / Reddit (as quoted by third parties)** = anecdotal. Flag as such.
- **This job is not a full modular kitchen carcass.** Kitchen work is **shutters (and any new drawer fronts) on existing granite**. Wardrobe is a **full niche carcass + three hinged leaves**. That changes where money should go.

### Failure modes that actually matter here

| Failure | What causes it | What stops it |
|---|---|---|
| Delamination | MR/UF glue + steam/monsoon; fake “710” stickers | Real BWP-class board + QR/dealer proof |
| Edge swell | Raw or PVC-poor edges; 0.8 mm laminate telegraphing | E3 ABS 2 mm kitchen / 1 mm wardrobe, full wrap |
| Hinge tear-out | Core gaps, 2 hinges on a 90 in door, cheap screws | Gap-free core (Club Prime / Boilo / HDHMR); 4–5 Sensys; factory screws |
| Sag | Tall uncalibrated shutters; weak hanging rod | Calibrated board or Club Prime; oval 30×15 mm rail + mid support |
| Termite/borer | Untreated core; site infestation | GLP / treated board **plus** site termite control. Board is not a building treatment. |
| Bedroom IEQ | High-formaldehyde UF boards in a closed wardrobe | Avoid MR UF if possible; E1/E0 claims only if the mill document is in hand |

### Moisture grades (do not confuse names)

| Grade | Typical Indian meaning | Use on this job |
|---|---|---|
| **MR (IS 303 MR)** | Moisture-resistant, usually UF glue. Humidity, not wetting. | **Do not** use in kitchen. Optional only for dry loft if already sealed — still not preferred. |
| **BWR (IS 303 BWR)** | Boiling-water *resistant*. Better than MR; not marine. | Acceptable kitchen loft only if BWP unavailable. Not first choice. |
| **BWP as IS 303 BWP** | Century’s **official** Sainik 710 claim: general-purpose BWP, **not** marine IS 710. | **Wardrobe** primary. Kitchen only if Club Prime / Boilo unavailable. |
| **BWP as IS 710** | Marine / boiling-waterproof phenolic plywood (BIS marine spec). | **Kitchen shutters** if staying in plywood: Club Prime (manufacturer claim). Verify stamp + QR. |
| **HDHMR** | High-density fibre board, moisture-*resistant*, calibrated. Swells irreversibly if edges fail. | Wardrobe alternate; kitchen loft if fully ABS-sealed. Not under-sink. |
| **Boilo (BWP FR HDF)** | Action Tesa boiling-waterproof, fire-retardant HDF. Density claimed >1000 kg/m³. | **Kitchen shutters** primary engineered option. Overkill/heavy for 90 in wardrobe doors. |

**Critical naming trap:** the product is called **Sainik 710**. Century’s own product page states that “Asli” BWP means compliance with **IS 303 BWP (general purpose plywood)** — not automatically **IS 710 marine**. Retailer copy in Bangalore often writes “Sainik 710 = IS:710”. Treat that as **marketing conflation**, not a certificate you have seen.

## 2. Primary recommendation (cost-effective **and** reliable)

**Split the spec. Do not buy one board for the whole house.**

### Kitchen shutters (small quantity — spend here)

**Primary: Action Tesa Boilo, 18 mm, plain (post-laminate with Century S1241 MT Latte 0.8 mm).**

Why this wins on first principles for *this* kitchen:

1. **Moisture:** Manufacturer positions Boilo as BWP FR HDF for kitchens and damp areas, with claimed high dimensional stability vs plywood (lower swell / linear expansion). Kitchen is steam + wipe-down, not a boat — but shutters see the steam.
2. **Hinge cups:** Homogenous core, no veneer gaps. Action Tesa claims screw withdrawal remains after boiling-water exposure. That is the failure mode that dumps a shutter on the granite.
3. **0.8 mm laminate:** Calibrated, smooth face. 0.8 mm Century StarLine telegraphs core gaps and thickness bounce. Boilo is built for post-lamination.
4. **Termite/borer:** Manufacturer cites **IPIRTI 1-year testing certificate** for termite proof — a **lab test duration**, not a 10-year furniture warranty. Still better than untreated commercial ply.
5. **Cost vs area:** Shutters-only means a few sheets. Boilo’s premium vs Sainik is small in rupees and large in hinge reliability.
6. **Fire-retardant:** Manufacturer claims **IS:5509**. Useful near hob; not a reason to use Boilo in the bedroom.

**Fabrication rules (non-negotiable):**

- Laminate **both faces** (or face + balancer) so 3000 K + steam do not cup the shutter.
- **2 mm E3 ABS**, matched to S1241, full perimeter including hinge-cup side after boring (or cup-area sealer).
- PUR or proven contact adhesive only if the shop can show a sample of 0.8 mm on Boilo without bubbles.
- Confirm local stock in Shimoga / Bhadravati / Bengaluru before locking. If the carpenter has never edged HDF, use the plywood alternate below rather than a first-time Boilo experiment.

### Wardrobe carcass + three doors (larger quantity — save here)

**Primary: CenturyPly Sainik 710, 18 mm (19 mm if the dealer’s 18 mm is chronically under-thickness), BWP grade as sold, QR-verified.**

Why this is the value-reliable wardrobe board:

1. **Availability:** Sainik is the carpenter default across Karnataka. Club Prime / Architect often need a preorder. A board that is not on the truck gets substituted with junk.
2. **Cost:** Century lists a national MRP language of about **?122/unit incl. GST** (unit ? 929 cm²) for Sainik 710 vs about **?171/unit** for Club Prime 19 mm. Wardrobe niche 54×90×19.20 in eats sheets; the delta is real.
3. **Moisture:** Official BWP (IS 303 BWP). Bedroom is dry vs kitchen, but Bhadravati monsoon + floor mopping at the plinth still punish MR. Spending BWP here is cheaper than a failed plinth.
4. **Termite:** Century claims borer/termite proof with **Glue Line Protection** and a **10-year** warranty on that claim (register via CenturyPromise). Still require site termite treatment.
5. **Carpenter practice:** Ply planes, screws, and repairs like wood. HDHMR/Boilo need discipline on edges and cups. For a 3-door site-built niche, ply is the lower execution risk if the shop is traditional.
6. **IEQ:** Official Sainik page does **not** state E0. Dealer pages sometimes say E1. **Do not print E0/E1 on the client PDF unless the mill certificate for that batch is in the file.** Phenolic BWP is generally preferable to UF MR in a closed wardrobe.

**Fabrication rules:**

- Scan **every sheet** with CenturyPromise before it is cut. Karnataka/Bengaluru counterfeit risk is well reported (see §6).
- **1 mm E3 ABS** matched to 84689 SU Idria Oak, all edges including shelf fronts and hanging-rod holes.
- Reject sheets with core gaps at the cut, face patches, or failed QR.
- 18 mm sides for hinge plates and rod brackets. Do not drop to 16 mm to save money on a 90 in door.

| Do not use | Why |

| **Sainik MR / Win MR / any MR in kitchen** | UF glue. Steam + monsoon. Classic 2–5 year delam. |

| **Boilo for the full 90 in wardrobe** | Density >1000 kg/m³ ? heavy leaves ? more hinges, more sag risk, more cost. FR is unused in a bedroom. Use Sainik or HDHMR. |
| **HDHMR as kitchen *carcass* if boxes are ever added under sink** | Moisture-resistant, not recoverably waterproof. Edges fail ? permanent swell. |
| **Architect Ply “because premium”** | Cost without a failure mode this job has. |
| **Local / unbranded hinges, clip-on dampers, “soft close” add-ons** | Dampers die in 18–24 months (trade commentary). Then slamming tears cups. |
| **Hettich Onsys as the kitchen hinge** | Value line. Sensys is the reliable mid-tier. |
| **Blum as default** | Excellent, 30–50% more, weaker spare-parts story outside metros. Not the value-reliable tier. |
| **Bar / D-pulls / knobs** | **Locked out.** Recessed / J-pull / finger-pull only, brushed stainless. |
| **MS hanging rod, chrome-on-MS that rusts** | Humidity. Use SS or proper nickel-plated oval rail with supports. |
| **Gloss / sparkle ABS; unmatched edge colour** | Locked: matt E3 matched to laminate. |
| **One-sided laminate on kitchen shutters** | Warp under steam and 3000 K. |

## 5. Hardware schedule (value-reliable tier)

**Pulls stay recessed brushed stainless.** Do not substitute bars. Match J-profile / integrated finger-pull to E3 edge thickness (2 mm kitchen, 1 mm wardrobe) so the recess does not chip the laminate.

Specify **brand + series + overlay type + quantity** in the BOQ. A quote that says “Hettich / branded hardware” is incomplete.

### 5.1 Hinges

| Location | Spec | Notes |
|---|---|---|
| **Kitchen shutters** | **Hettich Sensys 8645i**, 110°, integrated Silent System, nickel, **EN 15570 Level 3**, door 15–24 mm. Overlay crank to match existing granite/frame (0 / 9.5 / 16). Cup Ø 35 mm, TH 52. Mounting plates **System 8000**. | Integrated damper, not clip-on. 3D adjustment for out-of-square granite niches. |
| **Wardrobe 3 doors** | Same **Sensys 8645i** 110° overlay (or half-overlay on meeting stiles). | 90 in height: **5 hinges per leaf** (not 3). Heavy Idria + 18 mm. |
| Acceptable kitchen/wardrobe alternate | **Häfele** Salice / Silentia equivalent, named SKU, integrated soft-close. | Similar money; confirm India spare parts. |
| Acceptable **wardrobe-only** value cut | **Ebco** Auto / integrated soft-close (not a separate damper clip), ISO/BIFMA line. | ~30–50% cheaper. Do **not** use Ebco as the kitchen hinge spec. |
| Do not use | Hettich Onsys; Intermat + aftermarket damper; unbranded “SS hinge”; Blum unless client upgrades the whole hardware budget. | |

**Hinge screws:** use the screws in the Hettich box (typically ~3.5×15–17 mm cup screws). Predrill. Do not substitute 1-inch drywall screws.

### 5.2 Drawer channels (only if drawers exist)

Shutters-only kitchen may have **no new drawers**. If any drawer is built:

| Location | Spec |
|---|---|
| Kitchen drawers (pots / cutlery) | **Hettich KA 5632** telescopic, **45 kg**, full extension; or **KA 4732** Silent System **35 kg** if soft-close is required and load is light. Length = drawer depth, not 19.20 in blindly — measure clear inside. |
| Kitchen premium alternate | Hettich Quadro / InnoTech box drawer — only if the box is new, not a retrofit on masonry. |
| Wardrobe drawers (if any) | **Ebco STDS-I-SC** 35 kg soft-close **or** Hettich KA 4732. Clothing load is light. |
| Do not use | Bottom-mount roller channels; 25 kg slides on kitchen pots; “soft close” stick-on pistons. |

### 5.3 Locks

| Location | Spec |
|---|---|
| Wardrobe | **Godrej Curvo** furniture lock, **8010 (25 mm)** for 18–19 mm shutters, SS cover, dimple key. Official series: [godrejenterprises.com Curvo](https://www.godrejenterprises.com/locks-and-security/locks/furniture-locks/p/curvo). |
| If shutter stack is thicker (laminate + 19 mm + balancer > 25 mm) | **Godrej Curvo 8011 (32 mm)**. Measure finished thickness. |
| Kitchen | Usually **no lock**. If required, same Curvo 8010, SS, not painted MS. |
| Do not use | Cam locks with no brand; furniture locks that rust; magnetic catches as the only “lock”. |

### 5.4 Hanging (wardrobe)

Niche width **54 in** (~1370 mm). One oval rail will sag if unsupported.

| Item | Spec |
|---|---|
| Rail | Oval **30 × 15 mm**, chrome or SS. **Hettich** oval wardrobe rail **or Ebco WRF-RA** series. Cut length = inside width minus support allowance (Hettich SL 322: typically inside ? 7 mm — confirm SKU). |
| End supports | **Hettich SL 322** (3-screw) or **Ebco WRF-B2**. Screw into **18 mm** sides with 4×30 mm screws; do not punch through the outer laminate. |
| Mid support | **Required** at ~centre of 54 in. Extra SL 322 on a divider, or SL 786 under a shelf (max 19 mm shelf). |
| Height | Typical hanging: rail ~1000–1050 mm above carcass floor for shirts; confirm with client (saree vs shirts). Double hang only if depth 19.20 in and door swing allow — **19.20 in is tight**; single rail + shelf is the safe default. |

### 5.5 Screws and connectors

| Use | Spec |
|---|---|
| Kitchen, any wet-risk fixing | **SS304** wood screws / confirmat. Project already locked SS304 for wet risk. |
| Hinge cups / plates | Hettich-supplied. Predrill 2.5 mm. |
| Wardrobe carcass | Confirmat 7×50 or 6.3×50 into 18 mm; or 3.5×50 if traditional. Zinc-plated acceptable **inside** dry wardrobe; SS304 still preferred at plinth. |
| Hanging-rod brackets | 4×30 mm into 18 mm; SS304 or nickel-plated. |
| Granite / masonry hinge plates (kitchen retrofit) | Do not screw 15 mm into crumbling masonry. Use a **18 mm BWP/Club Prime** hanging strip or aluminium frame as specified in shop drawings. This is the #1 retrofit failure. |

### 5.6 Recessed pulls (locked)

- Brushed stainless **recessed** J-pull / finger-pull / integrated edge pull.
- Coordinate with **2 mm** kitchen ABS so the mill does not chip Latte.
- Wardrobe: same family, slimmer if needed for 1 mm ABS — still recessed, not a bar.
- Spare: 2 extra pulls + 1 extra Sensys pair + 1 m extra ABS + 1 laminate sheet offcut retained on site.

### Standards (do not invent)

- **IS 710** = BIS marine / BWP plywood specification (72-hour boil type tests live in the standard — we did not download the paid BIS PDF here).
- **IS 303** = general-purpose plywood (MR / BWR / and, in Century’s wording, BWP as a commercial grade).
- **IS 5509** = fire-retardant plywood (Action Tesa claims Boilo FR “confirming to IS:5509” — that is a **manufacturer claim** for an HDF board; attach the test report, do not assume BIS marking).
- **EN 15570** = furniture hinge durability classification (Hettich Sensys 8645i: Level 3 on the official shop page).
- **E0 / E1** = formaldehyde emission classes. Print only with a mill certificate for the **batch on site**.

## 8. Procurement checklist (Bhadravati / Karnataka)

1. Authorised **Century** dealer + **Action Tesa** dealer; get written SKU, thickness, grade, rate, GST.
2. Scan **CenturyPromise QR** on every Sainik/Club sheet before unloading.
3. Photograph **ISI / grade stamp** on sheet edge. If the kitchen plywood is sold as IS 710, the stamp must say so — “Sainik 710” printed on the face is not that stamp.
4. For Boilo: ask for **IS:5509 / IPIRTI / E1** copies. If they cannot produce paper, do not print those claims on the client PDF.
5. Hardware: Hettich **India** invoice with **8645i** (or named Häfele SKU). Open one box on site; logo on the hinge.
6. Site-measure granite openings and wardrobe plumb **before** cutting shutters.
7. Sample: 300×300 mm Latte on Boilo or Club Prime + 2 mm ABS, and Idria on Sainik + 1 mm ABS, viewed at **3000 K** next to granite.
