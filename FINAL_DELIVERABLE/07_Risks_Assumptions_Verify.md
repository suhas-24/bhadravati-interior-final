# 07 — Risks, Assumptions & Site Verification

---

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Fabricating from clear openings without overlay/reveal calc | Shutters too tight/loose; binding | Shop drawings after site measure; aluminium/laminate system chosen first |
| Granite thickness conflict (1.50 in vs 15 mm assumption) | Wrong reveals, hinge screws into void | Measure installed stone at multiple points |
| Out-of-plumb granite/RCC niche | Twist, gaps, warp | Measure top/mid/bottom; shims/straighterers; possibly tapered reveals |
| Dual-tone kitchen creep (old renders used Slate base + greige loft) | Dark kitchen + mismatch | Enforce S1241 MT Latte on **all** kitchen shutters |
| AI/visuals inventing openings, islands, TV walls | Client approves false geometry | Three-view QA set; reject non-plan-faithful images |
| Cool or orange LEDs | Latte/greige shift ugly | Sample LEDs with laminates at 3000 K |
| Humidity at sink bottoms / hinge cups | Swell, fungus | BWP/WPC, sealed edges, SS304, ventilation gaps |
| Hard water on granite + SS | Visual “dirty luxury” | Matte culture, wipe-dry habit, avoid mirror polish |
| Dust on open shelves / bouclé | Constant cleaning, looks aged | Closed storage, tight weaves, mid-tones |
| Narrow bathroom/wardrobe aisle (~2 ft annotated) | Pinch, door collision | Keep clear; verify; secondary path only |
| Concealed plumbing / DB boards | Service failure, unsafe | Access panels; never permanently seal damp zones |
| Window size conflicts in docs | Wrong curtain/furniture clearance | Site measure openings |

---

## Assumptions (explicit)

1. Overall studio relationship is approximately **21 ft × 18 ft**; plan is **not** a fabrication document.
2. Kitchen and wardrobe **labelled clear openings** in `dimension_register_v1` are the design baseline until superseded by signed site measure.
3. Kitchen remains **single-wall existing granite**; sink under window; fridge at extreme right — per brief/QA (confirm on site).
4. Main door inward clear ~**1051 mm** (prior handover note) — **unverified**.
5. Opening sizes from prior notes/plan overlays (bedroom / bath / study / kitchen windows) may conflict; **none are fabrication-authoritative**.
6. No structural change, false ceiling redesign, or electrical redesign is approved unless separately commissioned.
7. Client accepts **warm contemporary minimalism** over Japandi styling.
8. Budget currency/amounts TBD from local fabricator quotes.
9. Catalogue hex/RGB values are unofficial screen references from extracted shade data / visual approximation.
10. “Finished concept” floorplan furniture positions are circulation intent, not surveyed coordinates.

## Mandatory site verification checklist

### Kitchen

- [ ] Finished opening widths at counter, mid-height, loft (B1/B2/B3 + loft)
- [ ] Left/right plumb deviation; floor level
- [ ] Actual granite thickness; internal depth at 3 points
- [ ] Counter / loft / shelf absolute levels
- [ ] Window, sink, hob, plumbing, electrical, refrigerator clearances and swings
- [ ] Photograph tape end-to-end with IDs

### Wardrobe

- [ ] W/H/D at top, middle, bottom
- [ ] Granite partition thickness at 3 points; plumb/square
- [ ] Adjacent door/window swing; skirting/beam projection
- [ ] Internal shelf levels; wall moisture; services
- [ ] Confirm four-leaf hinge sides and straightener need

### Whole home

- [ ] All door/window W×H, sill, swing, mesh/grille
- [ ] Switchboard / ventilation / beam locations
- [ ] Stair/move-in path for sofa and shutter leaves
- [ ] Sample board under morning / afternoon / 3000 K
