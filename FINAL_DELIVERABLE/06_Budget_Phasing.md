# 06 — Budget Phasing

Currency not fixed in sources — use **relative tiers** (? bands to be filled after local quotes). Prioritise climate resilience and dimension-correct joinery before decorative spend.

---

## Priority ranking

1. **Kitchen shutters + wet-risk boards + matched edge + hardware** (daily use, humidity, hard water)
2. **Wardrobe four-leaf shutters + straightener + internals as needed**
3. **Paint system (walls/ceiling) + sample approval**
4. **Kitchen task lighting + key ambient points**
5. **TV cabinet (floating) + cable management**
6. **Sofa / bed / mattress** (comfort; can phase if existing usable)
7. **Study desk/chair/task lamp**
8. **Soft goods (rugs, curtains), optional accent paint**
9. **Decor / art** — lowest; optional omit

## Phased implementation

### Phase 0 — Verify (before spend)

- Signed site-measure sheet superseding register.
- Physical samples: NN9074, WW0005, S1241 MT, 84689 SU, 80236 DW, E3 edges, brushed SS handle, granite adjacency board.
- Quotation checklist: board brand/grade/thickness; laminate code/finish; edge brand/thickness; adhesive process; hinge/channel models; warranty exclusions; installation responsibility; spare availability.

### Phase 1 — Wet & storage core

- Kitchen shutter fabrication/install (same Latte base+loft).
- Seal wet edges; prove sink access.
- Wardrobe four-leaf install.
- Wall prep + paint NN9074 / ceiling WW0005.

### Phase 2 — Light & living function

- Kitchen task + ambient circuits.
- Floating TV cabinet + TV mount.
- Sofa / coffee table / rug as needed.
- Curtains for glare.

### Phase 3 — Sleep & work comfort

- Bedside lamps, bedding refresh.
- Study desk/chair/lamp; limited shelves.
- Optional GG7140 or study accent **only after** living with neutrals 2–4 weeks.

### Phase 4 — Optional polish

- Art, plants (real only if maintained), minor accessories — sparse.
- Spares kit logged.

## Cost-risk notes

- Dual-tone kitchen (rejected Concept C) increases future mismatch cost — avoided.
- Two oversized wardrobe doors increase warp/callback risk — avoided via four leaves.
- Gloss fronts increase hard-water + glare maintenance — avoided.
- Unverified PUR claims create false warranty comfort — require machine proof.
